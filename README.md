# Vector Orchestration

Este repositorio levanta los servicios **upload-api** y **vector-db-api** usando Docker Compose para facilitar la integración y despliegue conjunto.

## Requisitos

- Docker
- Docker Compose

## Cómo usar

Si tienes los repositorios `upload-api` y `vector-db-api` como carpetas hermanas:

```bash
docker-compose up --build
